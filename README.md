# Orb

Orb 是一款正在开发中的环境式桌面 AI 伴侣。

它的目标不是让用户主动打开 AI，而是让 AI 以低打扰的方式长期存在于桌面环境中，并在合适的时候主动提供帮助。

> An AI that is there before you ask.

## 当前状态

Orb 目前处于早期 Prototype / Alpha 阶段。

### 当前功能

- Q 版桌面角色
- 多帧自然眨眼
- 桌面互动与拖动
- ACTIVE / IDLE / DOZING 状态
- 全屏应用自动隐藏
- 前台应用使用时间检测
- 系统 Idle 检测
- 简体中文界面
- 本地预设台词
- Pause / Resume
- Local-first 隐私设计

## 隐私

Orb 当前版本：

- 不截图
- 不记录键盘输入
- 不读取剪贴板
- 不读取浏览器页面
- 不读取窗口标题
- 不上传用户活动记录

所有当前行为监测均在本地完成。

## 注意

Orb 目前属于早期测试软件。

由于安装程序尚未进行商业代码签名，Windows SmartScreen 可能提示“未知发布者”。

请只从本 GitHub Repository 的 Releases 页面下载 Orb。
